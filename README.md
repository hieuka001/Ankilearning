# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/107cc08f-fa9b-408b-8fde-252d2a9b24ba

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`

## AI Model

The app uses `gemini-2.5-flash` by default for all AI learning features, with `gemini-2.5-flash-lite` as a fallback for temporary quota/rate-limit/server errors.
